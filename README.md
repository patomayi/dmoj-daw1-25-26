# DMOJ DAW1 2025-2026

## English
This repository contains Java exercises and solutions developed for the DMOJ platform as part of the DAW1 course in 2025-2026. The source code is organized under `src`, with additional assets and screenshots stored in the `images` folder.

The main purpose of this project is to document and store the training exercises completed during the course, making it easier to review and improve solutions over time.

### Structure
- `src`: Java source code
- `images`: screenshots and supporting material
- `.idea`: IDE configuration files
- `.gitignore`: ignored files configuration

## Español
Este repositorio contiene ejercicios y soluciones en Java desarrollados para la plataforma DMOJ como parte de la asignatura DAW1 en 2025-2026. El código fuente está organizado dentro de `src`, y los recursos adicionales e imágenes se guardan en la carpeta `images`.

La finalidad principal del proyecto es documentar y guardar los ejercicios de entrenamiento realizados durante el curso, facilitando así la revisión y mejora de las soluciones con el paso del tiempo.

### Estructura
- `src`: código fuente en Java
- `images`: capturas y material de apoyo
- `.idea`: archivos de configuración del IDE
- `.gitignore`: configuración de archivos ignorados
